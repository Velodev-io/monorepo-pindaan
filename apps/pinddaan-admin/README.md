# Pinddaan Admin Dashboard 🛠️

The secure administrative console for managing the Pinddaan service network. This dashboard allows staff to oversee user accounts, process ritual bookings, and manage sacred service offerings.

## ✨ Features

- **User Management**: Unified view of all registered devotees and their activity.
- **Booking Oversight**: Real-time tracking and status management for ongoing ritual requests.
- **Service Configuration**: Ability to update ritual details, locations, and pricing.
- **Analytics**: Key performance indicators for the Pinddaan network growth and revenue.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Authentication**: Firebase Authentication
- **API Client**: Standardized consolidated `apiClient` for secure communication.
- **Icons**: Lucide React

## 🛠️ Development

Run the admin dashboard locally:
```bash
npm run dev
```

Ensure your `.env` is configured with the correct `NEXT_PUBLIC_FIREBASE_CONFIG` to allow staff authentication.
