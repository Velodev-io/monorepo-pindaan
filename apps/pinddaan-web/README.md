# Pinddaan Web 🌿

The Pinddaan Web application is a dedicated portal for devotees to book and coordinate sacred ancestors' rites, including Asthi Visarjan, Pind Daan, and Shraddha.

## ✨ Features

- **Booking Flow**: Intuitive, step-by-step process for selecting rituals, locations, and providing ancestral details.
- **Sacred Locations**: Integration with verified sites at Kashi (Varanasi), Haridwar, and Prayagraj.
- **Service Catalog**: Detailed information on Vedic rituals and Shastric traditions.
- **User Dashboard**: Secure access for devotees to track their bookings and view ritual certifications/videos.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Components**: Radix UI / Shadcn
- **State Management**: React Hooks
- **Icons**: Lucide React

## 🛠️ Development

Run the web app locally:
```bash
npm run dev
```

The app will be available at `http://localhost:3000` (depending on your port configuration).
